# Data card

`bloombot data build` downloads every file from its original publisher, converts labels to
the six revised Bloom levels, cleans and de-duplicates, and writes
`data/processed/questions.parquet` plus `data/processed/datacard.json` (every count below
comes from that file). The data itself is not in this repository, except a small sample for the web
UI's dataset explorer (`frontend/src/recorded/dataset.json`: up to 20 questions per source and
level, from the six sources whose licences allow it, each shown with its licence and citation).
The Indian school-board set (CC BY-NC, and the held-out test set) appears there as counts only;
`GET /v1/dataset` follows the same rule (`Source.public` in `src/bloombot/data/sources.py`).

## Sources

A *source* is one population of questions with one provenance. Several public files
re-package each other (Yahya's 600 questions appear in four of them), so loaders keep only
the rows that originate in their own population, and the build removes anything shared.

Where each comes from:

* **yahya2012** — Yahya, Toukal & Osman (2012), *Bloom's Taxonomy-Based Classification for Item
  Bank Questions Using SVM*, Studies in Computational Intelligence 431. File: supplement S2 of
  Mohammed & Omar (2020), PLOS ONE (the copy in BloomNet is byte-identical). Original taxonomy
  names; 100 per level.
* **mohammed2020** — Mohammed & Omar (2020), PLOS ONE 15(3): e0230442, supplement S1:
  141 open-ended questions "collected from several websites, books and previous work"
  (not exam papers). Original taxonomy names. 2 rows are also in Yahya and stay there.
* **sangodiah2017**, **gani2023** — real Malaysian university exam questions, revised labels,
  as released by Faraji et al. (2026), arXiv:2606.13684
  ([GitLab](https://gitlab.com/zrasoulkhani/bloom-classification-aied2026)). The released CSVs
  are used; the class counts in that paper's Table 1 do not match its own CSVs.
* **scaria2024** — Scaria, Chenna & Subramani (2024), AIED. 2,550 questions generated by five
  LLMs for a graduate data-science course; two experts rated each. Kept: both experts gave the
  same level **and** neither marked it not understandable, not answerable or off-topic.
* **indian_engineering** — Kaggle `vijaydevane/blooms-taxonomy-dataset` v5 (revised BT order).
  The file mixes five populations; we keep the Indian engineering exam questions by removing
  rows that are Yahya or Gani questions and rows found verbatim in two LLM-generated Kaggle sets
  (`dineshsheelam`, `abhaygotmare`). Almost no Evaluate/Create — that is what these papers ask.
* **indian_boards** — Das et al., Mendeley Data doi:10.17632/48nfn95jc8.2: CBSE/ICSE/NIOS
  grade-10 maths and science papers. Options are stripped from MCQs; rows labelled with more
  than one level are dropped. Non-commercial licence, so it is used **only for evaluation**.
  Many rows are sub-parts that depend on a shared stem ("find the first term").

## Label conversion

| Raw label | Level |
|---|---|
| Knowledge / Comprehension / Application / Analysis | Remember / Understand / Apply / Analyze |
| **Synthesis** | **Create** (level 6) |
| **Evaluation** | **Evaluate** (level 5) |
| BT1–BT6 in *revised* order (Devane v5, Scaria) | 1–6 |

The original taxonomy puts Synthesis before Evaluation; the revised one swaps them.
`parse_label` refuses to read a bare numeric code without being told the scheme, because
guessing silently swaps Evaluate and Create (Devane's own Kaggle versions disagree on it).

## Cleaning

| Step | Effect |
|---|---|
| Strip numbering, marks, CO/BT/L/K tags | a tag left in the text is the label itself |
| Repair double-encoded UTF-8 ("Newtonâ\x80\x99s") | 82 Indian-engineering rows |
| Drop garbled (`??`, mostly non-letters) and 1-word or >200-word rows | |
| Within a source: identical questions with different labels are all dropped | 60 + 57 rows |
| Across sources: exact and near duplicates (char 3–5-gram cosine ≥ 0.9) kept only in the earliest source | 1,770 rows from Devane v5 were copies |
| Paraphrase groups (cosine ≥ 0.8) | kept in one fold during CV |

## Known limitations

* Labels are single-annotator in most sources and follow local conventions (see the
  concept-shift figure in [DESIGN.md](DESIGN.md)). Reported agreement between Bloom annotators
  in the literature is moderate (e.g. κ = 0.70 for 940 biology items, Larsen et al. 2022).
* Indian sources have very few Evaluate/Create questions, so per-level scores for those
  levels on Indian data rest on tiny counts.
* `scaria2024` is LLM-generated; its phrasing is more regular than real exam questions.
* The contrast set (`data/probes/contrast_set.csv`, 58 items) was written and labelled by the
  authors of this repository; it should be re-labelled by two teachers before being cited.
